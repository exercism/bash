# Design

## Goal

The goal of this exercise is to introduce variables in bash scripts.

## Learning objectives

- Assign a value to a variable, with no spaces around the equal sign.
- Expand a variable's value with `$name` and `${name}`.
- Use descriptive, non-ALLCAPS variable names.
- Read command-line arguments through positional parameters.
- Provide a default value with `${name:-default}`.
- Capture the output of a command in a variable with command substitution.

## Out of scope

- Arithmetic expansion; `expr` is used instead.
- Arrays.
- Functions and `local` variables.
- Exported variables and the environment.
- Parameter expansions beyond default values.
- Conditionals and loops.

## Concepts

The Concepts this exercise unlocks are:

- `variables`

## Prerequisites

- `commands-and-arguments`
