# Design

## Goal

The goal of this exercise is to introduce commands and arguments in Bash scripts.

## Learning objectives

- Understand that a script is a sequence of commands executed in order.
- Distinguish a command name from its arguments.
- Understand that whitespace separates command words.
- Pass options, command programs, and filenames as arguments to executable commands.
- Use `echo` with zero, one, or several arguments to produce output.
- Use basic quoting to group words and preserve whitespace in an argument.
- Recognize the shebang and comments in a script.

## Out of scope

- Declaring variables and handling positional parameters; the filename variable is provided.
- Reading standard input.
- Detailed usage of `head`, `awk`, or `sed`.
- Conditionals and loops.
- Functions.
- Arrays and arithmetic.
- Pipelines and redirection.
- Quoting beyond simple literal arguments.

## Concepts

The Concepts this exercise unlocks are:

- `commands-and-arguments`
